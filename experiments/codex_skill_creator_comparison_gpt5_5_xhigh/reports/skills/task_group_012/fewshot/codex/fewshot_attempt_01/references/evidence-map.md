# Evidence Map

## General precedence

- Prefer authoritative records over drafts, summaries, or adjacent events.
- Use the answer template's exact enum labels.
- Keep arrays to plain IDs unless the template says otherwise.

## Recruitment or opening review

- Use interview feedback, offer register, cost ledger, notice packets, policy views, and audit or message evidence.
- Treat an accepted offer as the handoff gate for payroll work.
- Send follow-up only for the candidates the template asks about.

## Leave precedence

- Compare profile summary, leave ledger, assignment history, policy document, and audit detail.
- Use approved current-period assignment history when it conflicts with a stale profile summary and the ledger or audit confirms it.
- Include only leave-scope audit events requested by the template.

## Payroll readiness

- Use submitted payroll assignments as authoritative.
- Exclude draft or superseded payroll records.
- Tie accrual readiness to the submitted assignment plus the batch evidence the prompt asks for.

## Onboarding closeout

- Treat leave setup and payroll setup as separate evidence tracks.
- Approve only when the selected records are clean and the template's gate allows approval.
- Exclude draft records from both tracks.

## Folder or notice review

- Check folder readiness, required files, required tags, notice quality, and formal notice defects.
- Missing files or defective notices block closeout even when approval exists.
- Use only the approval history, folder, notice, and audit evidence the template asks for.

## Final answer

- Return JSON only.
- Keep source, gate, scope, and control labels normalized.
