# Liquor Code Vocabularies

This reference explains the meaning domains for liquor staff-package codes. The
answer template always defines the exact allowed values — use those values, not
the ones listed here. This reference helps you understand what each code
represents so you can map data to the right template codes.

## Covered risk codes

Risk categories that may be covered by an active settlement or control.

| Domain | What it means |
|---|---|
| `AFTER_HOURS` | Risk of after-hours service outside permitted operating times |
| `ASSAULT` | Risk of violent incidents at or near the premises |
| `CAMERA_COVERAGE` | Risk from inadequate camera surveillance |
| `FOOD_SERVICE_GAP` | Risk of operating without adequate food service, undermining restaurant character |
| `ID_CHECK` | Risk of failing to verify patron age |
| `MINOR_SALE` | Risk of selling alcohol to minors |
| `NOISE` | Risk of noise complaints from neighbors |
| `PATIO_BOUNDARY` | Risk of patio/outdoor service exceeding permitted boundaries |
| `PUBLIC_SAFETY` | Risk to public safety from premises operations |
| `SALE_TO_MINOR` | Specific risk of completed sale to a minor |
| `SAME_PREMISES` | Risk arising from prior license history at the same address |
| `TAX_HOLD` | Risk from unresolved tax obligations |

## Verification gap codes

Evidence or documentation that is missing, conflicting, or stale.

| Domain | What it means |
|---|---|
| Camera / photo evidence | Site photos or camera-system evidence is missing from the record |
| Floor plan | The floor plan is conflicting with other evidence or is stale/outdated |
| Control signage | Required control signage is missing, conflicting, or not current |
| Neighbor notice | Required neighbor notification is missing from the file |
| Police memo | The police memorandum conflicts with other evidence or has identity concerns |
| Open incident follow-up | An incident investigation remains open and unresolved |
| Tax clearance | Required tax clearance documentation is missing |
| Late-night monitoring | No late-night monitoring plan or evidence is on file |

## Standard obligation codes

Obligations that apply to the license class regardless of location.

| Code | What it means |
|---|---|
| `CCTV` | Closed-circuit television surveillance must be installed and maintained |
| `DELIVERY` | Delivery operations are regulated |
| `FOOD_SERVICE` | Food service must be available during operating hours |
| `HOURS` | Operating hours are restricted |
| `ID_CHECK` | Patron age verification is required |
| `NOISE` | Noise limits are enforced |
| `PATIO` | Outdoor/patio service area is restricted |
| `SECURITY` | Security personnel or measures are required |

## Location-specific control codes

These use the same vocabulary as standard obligations but represent controls
that are actively enforced at the specific location through settlements or
site-level evidence.

## First 90-day monitoring plan check codes

| Domain | What it checks |
|---|---|
| Camera / CCTV | Verify camera system exports footage correctly; walkthrough of camera and security setup |
| Control signage | Recheck that required signage is posted and current |
| Food service | Verify food service is available in the service area |
| ID check observation | Observe ID-checking practices at the premises |
| Late-night / after-hours | Visit during late-night closing to observe compliance with hours |
| Noise / patio boundary | Check noise levels and patio boundary compliance |
| Police memo follow-up | Follow up on police memo items that need resolution |
| Tax clearance | Verify tax clearance is obtained |
| Incident log review | Review incident logs for unreported events |

## Escalation trigger codes

Conditions that should cause field staff to escalate the license.

| Domain | What it means |
|---|---|
| After-hours violation | After-hours service has been observed or reported |
| Camera / CCTV failure | Camera coverage is missing or footage cannot be produced |
| Food service not available | Required food service is not being provided |
| Noise or patio breach | Noise limits or patio boundaries have been violated |
| Tax hold | An open tax hold has not been cleared |
| Violent incident | An unreported violent incident has occurred |
| Minor sale | A sale to a minor has been detected or reported |
| ID check failure | Age verification procedures are failing |
| Control signage not verified | Required signage cannot be confirmed |
| Board order conflict | A board order is in conflict with the current posture |
| Major incident | A major incident has been reported that requires review |
| Referred minor sale unresolved | A referred minor-sale case remains unresolved |
| Patio boundary failure | Outdoor service boundary has been breached |
